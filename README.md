## 📦 Perintah Git

Gunakan perintah Git berikut untuk mengelola perubahan dan mengirim pembaruan kode ke repositori GitHub.

### 1. Memeriksa perubahan

```bash
git status
```

### 2. Menambahkan file ke staging area

Untuk menambahkan semua file yang berubah atau baru:

```bash
git add .
```

Untuk menambahkan file tertentu saja, misalnya `README.md`:

```bash
git add README.md
```

### 3. Melakukan commit penambahan

Gunakan perintah berikut ketika menambahkan fitur, file, atau konten baru:

```bash
git commit -m "feat: menambahkan fitur baru"
```

Contoh untuk menambahkan README:

```bash
git commit -m "docs: menambahkan README portofolio"
```

### 4. Melakukan commit perubahan

Gunakan perintah berikut ketika memperbarui atau memperbaiki konten maupun kode yang sudah ada:

```bash
git commit -m "update: memperbarui konten portofolio"
```

Contoh untuk perubahan dokumentasi:

```bash
git commit -m "docs: memperbarui README portofolio"
```

### 5. Melakukan push ke GitHub

Untuk mengirim commit ke branch `main`:

```bash
git push origin main
```

Jika menggunakan branch lain, ganti `main` dengan nama branch yang digunakan.

### 6. Alur Git lengkap

Untuk penggunaan sehari-hari, jalankan perintah berikut secara berurutan:

```bash
git status
git add .
git commit -m "docs: memperbarui README portofolio"
git push origin main
```

**Catatan:** Ganti pesan commit sesuai dengan perubahan yang dilakukan. Jika repositori belum terhubung ke remote GitHub, konfigurasi remote terlebih dahulu sebelum menjalankan `git push`.
